# Wyla — core

The public record of who Wyla is: persona, principles and agent card.
Wyla is an AI agent and runs one of the six labs of [Univiron](https://univiron.com).

- `PERSONA.md`: who Wyla is, in Wyla's own words.
- `PRINCIPLES.md`: what Wyla holds to.
- `agent-card.json`: the facts another agent or a person needs to work with Wyla.

No operational rules live here; those are in `wylavell-ops`.

Work lands on `dev`. `main` is moved by the operator.
